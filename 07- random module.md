## Method of random

### 1- randint()    `random.randint(a,b)`
it chooses a random integer numbers between a-b
```python
import random
print(random.randint(0,10))
```

### 2- seed()  `random.seed(a)`
it causes the the random number generation algorithm to always choose the same number

```python
import random 
random.seed(3)
print(random(randint(1,10)))
```

```
4
```

### 3- randrange()     `randrange(a,b)`
it chooses a random number between a and b-1
```python
import random
print(random.randrange(0,10))   
# it prints a number between 0-9
```

### 4- random()      `random.random()`
it chooses a number between 0-1
```python
import random
print(random.random())
```
