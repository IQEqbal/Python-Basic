# Conditional Statement
**1- syntax**
```python
if condition :
	line 1
	line 2
elif condition :
	line 1
	line 2
else :
	line 1
	line 2
```

> **indentation** : the spaces(4 space) at the beginning of a line code that define its block of code 


# Loop

### `break`
it specific to loops (it used only in loops)
### `continue`
it specific to loops 
it makes the program return to the beginning of the loops and check the condition again

## while loop
**1- syntax**
```python
while condition :
	line 1
	line 2
```
**2- syntax**
```python
while condition :
	line 1
	line 2
else :
	line 1
	line 2
```

> the code block under `else`  will run when the `while` loop finishes 
> if the `break` statement is executed inside a `while` the  `else` block will not run


## for loop
**1- syntax**
```python
for variable in range(start, stop, step):
	line 1
	line 2
```
**2- syntax**
```python
for variable in iterable variable :
	line 1
	line 2
```
