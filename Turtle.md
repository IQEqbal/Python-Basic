### Methods of `Turtle()` or `pen`

| Methods              | Usage                                                                          |
| -------------------- | ------------------------------------------------------------------------------ |
| `forward(distance)`  | it takes to pen forword                                                        |
| `backward(distance)` | it takes to pen backward                                                       |
| `left(angle)`        | the  pen doesn't move just used to make an angle and turn it's direction (top) |
| `right(angle)`       | used to make an angle and turn it's direction (down)                           |
| `color("color")`     | color of pen                                                                   |
| `heading()`          | it returns the direction of pen `print(pen.heading())`                         |
| `position()`         | it returns the position of pen  `print(pen.position())`                        |
| `width(val)`         | for width of pen                                                               |


```python
import turtle

pen = turtle.Turtle()

pen.forward(100)
pen.left(90)

pen.forward(100)
pen.left(90)

pen.forward(100)
pen.left(90)

pen.forward(100)
pen.left(90)

tutle.done()
```
